# ④_収益化およびインフラ構築ロードマップ（未着手）

## 1. インフラ構築方針（未着手・今後のロードマップ）
本アプリケーションを Colab / 開発環境から、常時稼働の本番 Web サービスへ移行するためのインフラ構築ロードマップである。
ソース `02_RouteA_GoogleCloudRun_全体設計仕様書` および `03_RouteB_Cloudflare_Setup_Guide` に基づき、完全費用0円で運用できる構成を構築する。

## 2. Route A: Google Cloud Run 本番デプロイ手順
Google Cloud の無料枠（毎月 200万リクエスト、180,000 vCPU秒無料）を活用した本番ホスティング手順。

### ステップ 1: Docker コンテナ化
Dockerfile を作成し、Streamlit をコンテナ化する。

### ステップ 2: Secret Manager による API キー保護
GEMINI_API_KEY を Google Secret Manager に登録し、Cloud Run の環境変数へ安全に注入する。

## 3. Route B: Cloudflare 連携 ＆ カスタムドメイン設定手順
Cloudflare を前段に配置し、独自ドメインの設定、SSL/TLS 暗号化、セキュリティ強化、およびアクセス解析タグの挿入を行う。

### ステップ 1: DNS ＆ Custom Domain 設定
1. 独自ドメインを取得。
2. Cloudflare ネームサーバーへ委任変更。
3. Cloudflare 管理画面から CNAME レコードを設定。

### ステップ 2: Cloudflare Workers による解析タグ・広告タグ挿入
Cloud Run や Streamlit 側の Python コードを変更することなく、Cloudflare Workers を用いて HTML の head 内に Google Analytics (GA4) や 広告審査用スクリプトを動的注入する。

## 4. 収益化戦略 ＆ Google AdSense 承認獲得ロードマップ
1. **Google AdSense 広告収益（メイン）**
   - サイドバーおよび結果表示ページ下部へのディスプレイ広告掲載。
   - 無料ツールとして開放し、アクセス数（PV）に比例した広告収入を獲得。
2. **B2B プレミアムプラン / API 提供（将来構想）**
   - 企業向け社内規程一括チェックや API 連携の有料サブスクリプション展開。
