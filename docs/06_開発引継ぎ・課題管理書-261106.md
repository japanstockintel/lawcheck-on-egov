# e-Gov法令整合性チェッカー（legalscale.net）開発引継ぎ・課題管理書

## 1. エグゼクティブサマリーおよびプロジェクト全体像

本ドキュメントは、「e-Gov法令整合性チェッカー（`legalscale.net`）」のインフラ構築および本番環境公開の達成事項と、次回セッション以降で実施すべき残存タスク（Google AdSense承認、Search Consoleインデックス化、Cloudflare Workersでのタグ動的挿入など）を網羅的にまとめた開発引継ぎ書である。

本システムは、デジタル庁のe-Gov法令API v2とGoogle Gemini API（RAG構成）を組み合わせ、契約書や社内規定の法令整合性をリアルタイム監査するB2B向けリーガルテックWebアプリケーションである。Google Cloud Run（コンテナホスティング）とCloudflare（DNS・セキュリティ・Workers）の完全無料枠を組み合わせることで、**インフラ維持費0円**での本番運用を実現している。

## 2. これまでのチャットセッションで実現・完了したこと

本セッションにおいて、ドメイン取得からDNS切替、Google Cloud Runとのマッピング、SSL/TLS暗号化通信の確立までの一連のインフラ構築がすべて完了し、本番Webサイトとして正常稼働を開始した。

### 2.1. ドメインおよびネームサーバー設定の完了
* **ドメイン管理（バリュードメイン / Value Domain）**:
  * 独自ドメイン `legalscale.net` の管理画面にて、ネームサーバー設定を「デフォルト」から「カスタマイズ」へ変更。
  * Cloudflare指定のネームサーバー（`reese.ns.cloudflare.com` および `sofia.ns.cloudflare.com`）を設定し、トラフィックのCloudflare保護下への移管を完了。

### 2.2. ドメイン所有権検証とGoogle Search Console自動連携
* **ドメイン所有権の自動検証**:
  * Google Cloud Runにおけるカスタムドメイン追加に伴い、Google Search Consoleとの自動連携（DNS TXTレコード認証）を実施。
  * Cloudflare上にTXTレコード（`google-site-verification=...`）が正常に配置され、ドメイン所有権が即座に承認された。

### 2.3. Google Cloud Run カスタムドメインマッピングとCloudflare DNS構成
* **Cloud Runサービス**: `lawcheck-on-egov`（asia-northeast1）
* **DNSレコード完全構成**:
  * **Aレコード（IPv4アドレス 4本）**: `@`（`216.239.32.21`, `216.239.34.21`, `216.239.36.21`, `216.239.38.21`）
  * **AAAAレコード（IPv6アドレス 4本）**: `@`（`2001:4860:4802:32::15`, `34::15`, `36::15`, `38::15`）
  * **wwwサブドメイン用 CNAMEレコード**: `www` ➔ `@`（プロキシ済み 🟠）
  * **所有権検証用 TXTレコード**: `@` ➔ `google-site-verification=...`

### 2.4. SSL/TLSハンドシェイクの確立と本番疎通確認
* **SSL Error 525の全自動解消**:
  * 初期アクセス時に発生した「Error 525 (SSL handshake failed)」は、Google Cloud Run側でのSSL証明書自動発行タイムラグによるものであり、時間経過に伴い全自動で解消された。
* **HTTPS完全対応**:
  * `https://legalscale.net` および `https://www.legalscale.net` の両系において、鍵マーク付きの安全な暗号化通信（SSL/TLS）でStreamlitアプリが正常動作することを確認完了。

## 4. 残された課題および次回セッションでの実施タスク（ロードマップ）

独自ドメインでの本番公開が完了したため、次のフェーズでは**「アクセス解析の導入」「AdSense審査用タグの動的挿入」「Google AdSense申請と承認」「SEO/インデックス化」**を進める。

```
【第1フェーズ：完了】                   【第2フェーズ：次回実施】
 [独自ドメイン設定]                     [Google Search Console インデックス登録]
        ↓                                        ↓
 [Cloud Run ドメインマッピング]         [Cloudflare Workers で AdSense/GA4 タグ挿入]
        ↓                                        ↓
 [SSL/TLS 疎通確認（完全公開）] ───>    [Google AdSense 審査申請 ＆ 承認獲得]
```

### 優先タスク 1: Google Search Console でのサイトマップ・インデックス登録
1. **URL検査とインデックスリクエスト**:
   * Google Search Consoleにログインし、`https://legalscale.net` および `https://www.legalscale.net` のトップページに対するインデックス登録をリクエストする。
2. **サイトマップ提出**:
   * 今後、主要ページのインデックス化を促進するための構成を確認する。

### 優先タスク 2: Cloudflare Workers を活用した AdSense / Analytics タグの動的注入
* **目的**: 本体のPythonコード（`app.py`）を一切書き換えることなく、HTMLの `<head>` 内に Google AdSense 審査コードおよび Google Analytics 4 (GA4) のトラッキングコードを自動挿入する。
* **実施手順**:
  1. Cloudflare ダッシュボードにて「Workers & Pages」を開き、新規 Worker を作成。
  2. `HTMLRewriter` アピアランス API を用いて、Response HTMLの `</head>` 直前にタグを自動埋め込みするスクリプトを設置。
  3. Worker Route を `legalscale.net/*` および `www.legalscale.net/*` にバインド設定。

### 優先タスク 3: Google AdSense 審査申請と承認向けコンプライアンスチェック
`05_UXデザインおよびAdSense承認向け仕様固定方針書.md` に定められた以下の必須要件が画面上に正しく表示されているか再点検し、AdSense審査を申請する。

* [ ] **免責事項（Disclaimer）**: 非弁行為の防止および弁護士法72条遵守の明確な表記（AI回答が法的助言でない旨）。
* [ ] **プライバシーポリシー**: Cookieの取り扱い、個人情報保護方針、Google AdSense等の広告配信に関する記載。
* [ ] **お問い合わせフォーム**: ユーザーおよび権利者からの連絡窓口（Googleフォーム等の設置）。
* [ ] **AI非学習宣言**: 入力データがAIモデルの再学習に使用されないセキュリティポリシーの提示。
* [ ] **特定商取引法に基づく表記・運営者情報**: AdSense承認率を向上させるためのクリアなサイト運営者情報。
