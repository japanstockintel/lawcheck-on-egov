# ①_全体像_システムアーキテクチャ概要書

## 1. システム目的・コンセプト概要
本システム（正式サービス名：**e-Gov直結 法令整合性チェッカー**）は、デジタル庁が提供する「e-Gov 法令API Version 2」の公式現行条文データと、Google の大規模言語モデル「Gemini 3.8 Flash」をリアルタイム直結させた次世代の法令検証・AI添削Webアプリケーションである。

オウンドメディアの法務関連記事、社内規程・就業規則の改定ドラフト、人事労務・契約書相談、広報文などのテキストに含まれる法令に関する記述を形式的かつ機械的に公式条文と照合し、「条・項・号」単位の明確な法的根拠と改善文案を自動生成する。

### 本システムのコア理念
1. **確定事実とAI解釈の厳密な峻別**
   - 国の公式条文データ（e-Gov API）を「確定事実」とし、行政ガイドライン・判例・AIの推論を「補足解釈」として明確に分離して表示する。
2. **ハルシネーションの徹底排除**
   - AI独自の「あやふやな法令記憶」に頼らず、必ず e-Gov API から取得した生の正規条文XMLをプロンプトに注入（RAG / Context Injection）して検証を行う。
3. **完全費用0円・爆速レスポンス設計**
   - Google Cloud Run 無料枠、Cloudflare Tunnel / Workers、および Gemini REST API（無料枠）を活用し、インフラコスト完全0円で1〜2秒の爆速レスポンスを実現する。

## 2. 全体技術スタック・コンポーネント
本システムは、保守性・堅牢性・コストパフォーマンスを極限まで高めた以下のモダン技術スタックで構成されている。

| レイヤー | 採用技術・サービス | 役割・機能 |
| :--- | :--- | :--- |
| **ユーザーインターフェース** | **Python (Streamlit)** | 直感的なレスポンシブWeb画面、プログレス表示、レポート・エビデンス表示 |
| **法令データベース** | **デジタル庁 e-Gov 法令API v2** | 国の全現行法令・政省令の正規条文XMLおよび改正履歴メタデータのリアルタイム取得 |
| **生成AI / LLM** | **Google Gemini 3.8 Flash (REST API)** | 略称の正規化、文脈条文特定、委任規定検出、法令照合監査レポート生成 |
| **サーバーインフラ** | **Google Cloud Run (Route A)** | Dockerコンテナによるサーバーレスホスティング、オートスケール (0〜) |
| **ネットワーク / セキュリティ** | **Cloudflare (Route B)** | Custom Domain DNS、SSL/TLS、Cloudflare Tunnel (ポート開放不要)、Workers (アクセス解析タグ挿入) |
| **認証・秘密情報管理** | **Google Secret Manager / Streamlit Secrets** | Gemini API キー等の安全な暗号化保持 |

## 3. データフロー ＆ 処理シーケンス
ユーザーが文章を入力してから、監査レポートが出力されるまでの全体処理フローは以下の3ステップで実行される。

```
【ユーザー入力】（例: 「労基法36条では時間外労働が無制限...」）
       │
       ▼
【Step 1: Gemini 略称正規化・条文特定】 (call_gemini_api)
  ・入力文章から法令名（略称・通称含む）を抽出し、e-Gov正式名称に変換（例: 労基法 ➔ 労働基準法）
  ・文脈から該当する可能性の高い条文番号（例: 第36条、第115条等）を推定特定
       │
       ▼
【Step 2: e-Gov 法令API v2 リアルタイム取得】 (EGovLawAPIClient)
  ・GET /laws または /keyword で法令IDを取得
  ・GET /law_revisions で施行ステータス（現行・失効等）を確認
  ・GET /law_data/{law_id} で正規条文XML（RAW）を高速取得
  ・ElementTree によるXMLパースで特定条文（Article/Paragraph/Sentence）をピンポイント抽出
  ・「政令で定める」「省令で定める」等の委任規定を検出した場合、関連政省令（施行規則等）を連鎖取得
       │
       ▼
【Step 3: Gemini 最終法的監査・添削レポート生成】 (audit_with_gemini)
  ・取得した公式条文XMLデータ + 委任政省令データをプロンプトに注入
  ・断定・決めつけ禁止ガードレールを適用し、(A)確定事実と(B)AI補足解釈を分離出力
  ・全体の修正文案（完成版）およびトークン統計を画面に表示
```
