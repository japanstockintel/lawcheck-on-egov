# ⑤_UXデザインおよびAdSense承認向け仕様固定方針書

## 1. ドキュメントの目的 ＆ 永久固定の決定事項
本ドキュメントは、「e-Gov直結 法令整合性チェッカー」の UI/UX デザイン、画面レイアウト構造、法的表記文言、AI ガードレール、および AdSense 承認用必須項目を永久に定義・固定し、今後の開発継続における「先祖返り（要素の脱落・デザイン劣化）」を完全防止するためのマスター仕様書である。

---

## 2. 基本識別情報 ＆ 正式サービス名
- **正式サービス名（サイト名）**: `e-Gov直結 法令整合性チェッカー`
- **対象領域**: 全日本法令・政省令・施行規則のリアルタイム整合性検証・添削
- **コード提供ポリシー**: **新ノートブックでの開発開始段階において、最新の `app.py` はユーザー（当方）より直接提供する。** AI側が旧コードを独自判断で上書き・先祖返りさせることを厳禁とする。

---

## 3. UI/UX・画面レイアウト階層構造（最上部優先）

画面は以下の 5 段階の優先順位で上から下へ配置する。

### 階層 1: メインヘッダー（ヒーローカード）
* **配置**: 画面の最上部（サイドバーや入力欄より上位の最優先エリア）。
* **デザイン**: インディゴ・ダークネイビー (`#0f172a` 〜 `#1e3a8a`) のグラデーションカード (`.hero-card`)。
* **要素**:
  * ガラス調ピルバッジ: `🏛️ デジタル庁 e-Gov 法令API v2 直結` / `🛡️ ハルシネーション防止・事実峻別設計`
  * ベクター描画 SVG シールドアイコン ＋ タイトル `e-Gov直結 法令整合性チェッカー`
  * サブタイトル: `確定法令とAIの推論を明確に峻別する、次世代の法令検証エンジン。`

### 階層 2: 例文選択 ＆ テキスト入力エリア
* プリセット例文の選択肢 dropdown。
* テキストエリア (`st.text_area`): 500文字制限、プレースホルダー付き。

### 階層 3: 照合基準エクスキューズボックス（入力窓直下）
* **配置**: テキストエリアのすぐ直下に配置。
* **デザイン**: 左側に青いアクセントラインを持つ背景カード (`.excuse-box`)。
* **文言**:
  > `💡 照合基準について: 本ツールは「e-Gov 法令API Version 2」の仕様に基づき、本日時点で施行されている国の公式現行条文を基準にリアルタイム照合を行います。未施行の改正予定内容（例: 将来の施行日など）は、APIの仕様上本文データが未反映のため「現行法と差分あり」として判定される場合があります。`

### 階層 4: 実行ボタン
* 幅広・高視認性のプライマリボタン (`🔍 法令チェックを実行`)。ホバーアニメーション付き。

### 階層 5: 監査結果 ＆ エビデンス表示
* 3ステップ実行ステータスボックス (`st.status`)。
* マークダウン形式の添削レポート (`audit_with_gemini` の出力)。
* 公式条文 XML アコーディオンタブ (Tab 1: 参照条文 / Tab 2: トークン消費統計)。

## 4. サイドバー AdSense 必須 4 大要素

サイドバー (`with st.sidebar:`) には、AdSense 審査およびユーザー信頼性確保のため、以下の 4 大要素を必ず設置する。

### ① `ℹ️ 当サービスについて（About）`
* **内容**: サービス目的、e-Gov API 直結の技術的意義、オウンドメディア・就業規則チェックへの活用シーンの明記。

### ② `🔒 プライバシーポリシー`
* **内容**: Cookie 使用、第三者配信広告の表記、および**以下の AI 非学習宣言の完全明記**：
  > `※ 本プログラムではGemini API 経由で処理を行っているため、入力された文章が AI の学習データとして二次利用・蓄積されることは一切ありません。`

### ③ `⚖️ 免責事項・利用規約`
* **内容**: **非弁行為（弁護士法第72条）の防止**、法的助言の非該当性、および利用者の責任制限を明記。

### ④ `✉️ お問い合わせ・運営者`
* **内容**: 運営事務局名、および動的 Google フォームリンク (`st.secrets["CONTACT_FORM_URL"]`) の設置。

### サイドバー最下部キャプション
* 再度の AI 非学習宣言 ＋ `Powered by e-Gov API v2 & Gemini 3.8 Flash`

## 5. AI プロンプト ガードレール仕様 (`audit_with_gemini`)

プロンプト内には、以下の断定・決めつけ禁止ルールを常時注入する。

```text
【最重要：断定・決めつけの禁止】
1. 入力文章に特定の施行時期（例: 2026年12月等）や将来の制度改正が明記されている場合、提供された現行法令データや自身の知見に見当たらないからといって、直ちに「誤り」「誤記」「混同」と決めつけて断定することを厳禁とします。
2. データで照合できない・未施行の場合は、以下のように明確かつ誠実に回答してください：
   - 「現行の e-Gov 法令API（本日時点）の確定データでは該当する条文が照合できませんでした。」
   - 「ただし、行政機関（厚生労働省等）からの個別通知、公的広報、または今後施行予定の政省令・改正法に基づく記述である可能性がありますので、公式発表をご確認ください。」
```

## 6. 先祖返り防止の全約束項目
1. タイトル `e-Gov直結 法令整合性チェッカー` を変更しない。
2. ヒーローヘッダーを最上部から移動させない。
3. 入力窓直下のエクスキューズボックスを消さない。
4. サイドバーの AdSense 4 大要素（About / プライバシーポリシー / 免責事項 / お問い合わせ）を削らない。
5. AI 非学習宣言文言を漏らさない。
6. `audit_with_gemini` の決めつけ禁止プロンプトを外さない。
7. **新ノートブックでの開発開始時は、ユーザーから提供される最新 `app.py` をベースとして作業を開始する。**
